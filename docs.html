واجهات الـ API الحية

كل النداءات على أساس https://ahmed2404843.app.n8n.cloud/webhook. CORS مفتوح للعرض من أي دومين.

الغرضMethodPath
استقبال طلب التحاق (OCR, تحقق, فحص, تقييم, قرار)POST/onboardx-intake
لوحة طابور المراجعة (HTML)GET/onboardx-review
صفحة حالة مفصلة (HTML)GET/onboardx-review-case?id=APP_ID
تسجيل قرار المراجعPOST/onboardx-review-action
إحصاءات حية (JSON)GET/onboardx-stats
استعلام عن حالة برقم الطلب (JSON)GET/onboardx-api-case?id=APP_ID

مثال: إرسال طلب التحاق

curl -X POST https://ahmed2404843.app.n8n.cloud/webhook/onboardx-intake \
  -H 'Content-Type: application/json' \
  -d '{
    "merchant_id": "STORE-102",
    "channel": "qr",
    "national_id": "29901011501234",
    "consent": true,
    "phone": "01012345678",
    "id_front_base64": "<base64 jpeg>",
    "id_back_base64": "<base64 jpeg>"
  }'

الرد: {"application_id":"OBX-...","status":"APPROVE|REVIEW|REJECT|COMPLIANCE_HOLD","score":N,"credit_limit_egp":N,"reasons":[...]}

قرار المراجع

curl -X POST https://ahmed2404843.app.n8n.cloud/webhook/onboardx-review-action \
  -H 'Content-Type: application/json' \
  -d '{"application_id":"OBX-...","reviewer":"reviewer@flexipay.demo","action":"APPROVE","reason":"documents verified"}'
